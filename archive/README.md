# Archive Notes

This directory holds material that is still worth keeping for provenance, but no longer needs to sit at the workspace root.

- `memos/` contains older critique-loop and editor-prep drafts.
- `plans/` contains historical execution roadmaps and work-completion notes that no longer drive the active workflow.
- `status/` contains point-in-time session snapshots that are not part of the active manuscript flow.
- `misc/` contains small leftovers that are useful to retain but not useful to keep at the top level.

Archive by moving, not deleting, when a file is historical, superseded, or useful only for provenance.
