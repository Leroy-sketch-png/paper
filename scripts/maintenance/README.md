# Maintenance Utilities

This folder contains one-off or low-frequency helper scripts that are not part of the main experiment or manuscript pipeline.

- `download_falcon.py` is preserved for provenance but was superseded by `curl.exe` during artifact download.
- `fix_window.py` is a targeted repair script for `window.md` and is not part of the normal workflow.
- `pdf_to_markdown.py` is a utility for extraction work, not a core research pipeline entry point.

Keep active experiment and manuscript scripts at the workspace root; move only incidental maintenance tools here.
