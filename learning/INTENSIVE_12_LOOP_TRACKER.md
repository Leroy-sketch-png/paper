## Performance Rule

Use this grading scale after each loop:

- 0 = I mostly copied the notes.
- 1 = I roughly understand but cannot explain clearly.
- 2 = I can explain clearly with minor gaps.
- 3 = I can explain, predict, and apply without notes.

If you score:

- `0` or `1`: repeat the same loop tomorrow.
- `2`: move forward, but revisit on Day 3.
- `3`: move forward and teach it within 24 hours.

## Completion Rule

You finish the intensive track only if you can do all of these without notes:

1. Explain TCP in CI in plain language.
2. State the original paper's regime story correctly.
3. Explain pretrained MART and why it matters.
4. Name and explain the four realism gaps.
5. Distinguish verified results from framework or staged work.
6. Explain how the original paper and our paper fit together instead of treating them as enemies.
